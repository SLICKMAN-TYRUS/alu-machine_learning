# Q-learning

Q-learning on OpenAI Gym's FrozenLake environment.

| File | Description |
|------|-------------|
| 0-load_env.py | Loads the FrozenLake environment |
| 1-q_init.py | Initializes the Q-table |
| 2-epsilon_greedy.py | Epsilon greedy action selection |
| 3-q_learning.py | Trains the agent with Q-learning |
| 4-play.py | Plays an episode with the trained agent |
