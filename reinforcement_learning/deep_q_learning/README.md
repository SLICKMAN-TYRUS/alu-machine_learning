# Deep Q-Learning

Trains a DQN agent on Atari's Breakout with keras-rl.

| File | Description |
|------|-------------|
| train.py | Trains the agent and saves the policy network to policy.h5 |
| play.py | Loads policy.h5 and displays a game with a greedy policy |

Run `./train.py` first, then `./play.py`.
